Como funciona

Do WhatsApp à resposta em segundos

1

Aluno envia mensagem

No WhatsApp Business da escola. Verificação por RA na primeira mensagem.

2

IA classifica o intent

Claude API identifica o que o aluno precisa entre 40 categorias diferentes.

3

Busca os dados reais

Consulta o banco acadêmico ou ERP. Nunca inventa — só usa dados reais.

4

Gera a resposta

Resposta personalizada com o nome do aluno e os dados corretos.

5

Envia via WhatsApp

Resposta entregue em menos de 3 segundos. Histórico salvo no painel.

6

Gestor acompanha

Dashboard em tempo real, alertas de evasão, relatórios semanais por email.

Diferenciais

Construído para não falhar

🧠

Multi-IA com Circuit Breaker

Anthropic → Groq → Gemini em failover automático. Se todos caem, a Billie responde offline com templates.

🛡️

Segurança & LGPD

CPFs mascarados, isolamento por tenant (RLS PostgreSQL), JWT + refresh, HMAC no webhook, conformidade LGPD.

📊

Dashboard em tempo real

Conversas, tickets, satisfação, custo IA vs humano, score de evasão — tudo visível no painel admin.

🚨

Alerta de evasão

Score 0–100 calculado de hora em hora. Identifica alunos em risco antes de desistirem.

🔌

Integração com ERPs

Sophia (Prima), TOTVS RM Educacional e REST genérico. Credenciais encriptadas com Fernet.

📱

PWA completo

Painel admin instalável como app. Push notifications, offline-first, funciona no celular do gestor.

⚡

Multi-tenancy

Cada escola é isolada. RLS no PostgreSQL garante que dados nunca vazam entre instituições.

📈

Monitoramento robusto

Prometheus + Grafana + Loki + AlertManager. 9 alertas customizados para o time de operações.

😊

Análise de sentimento

Detecta frustração, satisfação e urgência em cada mensagem. Prioriza atendimentos críticos automaticamente.
